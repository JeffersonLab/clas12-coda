* Quick Start

** Setup Environment Variables
- bash example
#+begin_src shell
export LINUXVME=${HOME}/linuxvme
export LINUXVME_INC=${LINUXVME}/include
export LINUXVME_LIB=${LINUXVME}/Linux-$(uname -m)/lib
export LINUXVME_BIN=${LINUXVME}/Linux-$(uname -m)/bin
export LD_LIBRARY_PATH=${LINUXVME_LIB}:${LD_LIBRARY_PATH}
#+end_src
- tcsh example
#+begin_src shell
setenv LINUXVME ${HOME}/linuxvme
setenv LINUXVME_INC ${LINUXVME}/include
setenv LINUXVME_LIB ${LINUXVME}/Linux-`uname -m`/lib
setenv LINUXVME_BIN ${LINUXVME}/Linux-`uname -m`/bin
setenv LD_LIBRARY_PATH ${LINUXVME_LIB}:${LD_LIBRARY_PATH}
#+end_src

** Compile and install userspace driver
- make build directory, and generate Makefiles with cmake for installation into =$LINUXVME=
  #+begin_src shell
  mkdir build
  cmake -S . -B build -D CMAKE_INSTALL_PREFIX=$LINUXVME
  #+end_src
  
- build and install
  #+begin_src shell
  cmake3 --build build
  cmake3 --install build
  #+end_src
  + driver, headers, and stand-alone programs are installed:
    #+begin_example
    ${LINUXVME}/include/jvme.h
    ${LINUXVME}/include/dmaPList.h
    ${LINUXVME}/Linux-$ARCH/lib/libjvme.so
    ${LINUXVME}/Linux-$ARCH/lib/libjvme.a
    ${LINUXVME}/Linux-$ARCH/bin/vme_display
    ${LINUXVME}/Linux-$ARCH/bin/vme_modmem
    ${LINUXVME}/Linux-$ARCH/bin/vme_sysreset
    #+end_example
- uninstall accomplished with
  #+begin_example
  xargs rm -v < build/install_manifest.txt
  #+end_example
    
** Compile and install kernel driver
- change to kernel driver directory, build and install (sudo privileges required)
  #+begin_src shell
  cd kernel_driver
  sudo make
  sudo make install
  #+end_src

** Kernel Drivers

*** JVME

**** VME Master Windows
- Virtual Memory mapped to VME Address spaces
- These are the default windows used at JLab
| Address Space | Modifier | Size  |       Base | Device File |
|---------------+----------+-------+------------+-------------|
| A16           |     0x29 | 64kB  |        0x0 | m_a16       |
| A24           |     0x39 | 16MB  |        0x0 | m_a24       |
| A32           |     0x09 | 256MB | 0x08000000 | m_a32       |
| CRCSR         |     0x2F | 16MB  |        0x0 | m_crcsr     |

**** VME Slave Window
| Address Space | Modifier | Size |       Base | Device File |
|---------------+----------+------+------------+-------------|
| A32           |     0x09 | 4MB  | 0x18000000 | s_a32       |


*** CMEM
- kernel driver for allocation of contiguous memory (data buffers) for DMA operations.

**** kernel arguments

| debug          | 1 = enable debugging, 0 = disable debugging                      |
| errorlog       | 1 = enable error logging, 0 = disable error logging              |
| gfpbpa_size    | The amount of RAM in MB that will be pre-allocated               |
| gfpbpa_quantum | The size (in MB) of a page used for the pre-allocation           |
| gfpbpa_zone    | 0: Anywhere in the RAM,  1: In the 32 bit address range          |
| numa_zones     | The number of NUMA IDs for which buffers are to be pre-allocated |

**** =proc= files
- =/proc/cmem_rcc=
#+begin_example
CMEM RCC driver (JLab Release)

The driver was loaded with these parameters:
gfpbpa_size    = 512
gfpbpa_quantum = 4
gfpbpa_zone    = 1
numa_zones     = 1

alloc_pages and alloc_pages_node
   PID | Handle |         Phys. address |               Size | Locked | Order | Type | Name

GFPBPA (NUMA = 0, size = 512 MB, base = 0x000000006c400000)
   PID | Handle |         Phys. address |               Size | Locked | Type | Name
 
The command 'echo <action> > /proc/cmem_rcc', executed as root,
allows you to interact with the driver. Possible actions are:
debug    -> enable debugging
nodebug  -> disable debugging
elog     -> Log errors to /var/log/messages
noelog   -> Do not log errors to /var/log/messages
freelock -> release all locked segments
#+end_example

** Software Library - Basic Usage

*** Open and close access to VME resources
#+begin_src C
int32_t  vmeOpen();
int32_t  vmeClose();
#+end_src

*** Single Cycle Read / Write
#+begin_src C
uint8_t  vmeBusRead8(int32_t amcode, uint32_t vmeaddr);
uint16_t vmeBusRead16(int32_t amcode, uint32_t vmeaddr);
uint32_t vmeBusRead32(int32_t amcode, uint32_t vmeaddr);
void vmeBusWrite8(int32_t amcode, uint32_t vmeaddr, uint8_t val);
void vmeBusWrite16(int32_t amcode, uint32_t vmeaddr, uint16_t val);
void vmeBusWrite32(int32_t amcode, uint32_t vmeaddr, uint32_t val);
#+end_src

*** DMA
#+begin_src C
int32_t  vmeDmaConfig(uint32_t addrType, uint32_t dataType, uint32_t sstMode);

int32_t  vmeDmaDone();
